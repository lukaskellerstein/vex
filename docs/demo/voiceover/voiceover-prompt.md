/media-generate

Generate a voiceover for my VEX demo video.

Notes are at: plugins/media-plugin/skills/speech-generation/references/vex-demo-voiceover-notes.md

Tone: Product Demo.
Voice: confident, clear, modern — good for a SaaS product demo.

The agent will then:

1. Read your notes
2. Pick a voice and test its speaking pace
3. Write a proper voiceover script (the markdown table format from voiceover.md)
4. Generate each segment as separate TTS calls
5. Trim, pad, and assemble into a final WAV file
