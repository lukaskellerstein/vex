Retro Robot Variants

5 retro styles with long animation cycles (4-8s) — watch each for the full loop before deciding

1. Coder

4s cycle

Rapid typing bursts, pause to think (amber LED), code scrolls across chest screen

2. Builder

5s cycle

Hammering with sparks, holds piece with left arm, pauses to inspect, progress bar fills

3. Analyst

6s cycle

Scans left-right, thinks, nods, takes notes. Dual visor, data bars with anomaly alerts

4. Welder

7s cycle

Welds at 3 spots, arc glow + spark spray, visor dims for protection, body heats up

5. Operator

8s cycle

Flips switches, pushes buttons, turns knobs, pulls lever, double-take, LED status board
